# 2026 서울 크리스마스 마켓 5곳

캐러셀 7장, 인스타그램 릴스, 유튜브 Shorts.

```bash
cd src
python3 render.py carousel   # output/slide1~7.png
python3 render.py reels      # output/reel.mp4, reel_cover.png
python3 render.py shorts     # output/shorts.mp4
```

문구 위치: 마켓 정보는 `src/build.py`(캐러셀)와 `src/reel/reel_build.py`(영상) 양쪽, 후킹·아웃트로·CTA는 `src/reel/make_variants.py`.
