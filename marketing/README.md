# 마케팅 콘텐츠

로킷 SNS 콘텐츠(인스타그램 캐러셀·릴스, 유튜브 Shorts) 소스.

- 폴더: `YYYY-MM-DD-주제/` (만들기 시작한 날짜). 같은 주제를 다시 만들면 폴더를 복사해 새 날짜로.
- 소스는 `src/`, 결과물은 `output/` (git 제외, `src/render.py`로 다시 만든다).
- 공통은 `common/`: 브랜드(`brand/`: 폰트, 로고, 아이콘, 색 토큰 `brand.css`), 렌더링 함수(`render.py`).
  지도 경계는 앱 데이터(`apps/web/public/geo`)를 그대로 쓴다.
- 각 콘텐츠 README에 사실관계 근거 링크를 남긴다.
- 필요: Python 3, ffmpeg, gstack `browse` (경로가 다르면 `BROWSE` 환경변수).

## 체크리스트

- 첫 프레임부터 제목이 보이게 (페이드인 금지)
- 후킹 문구는 근거가 있는 사실로
- 정보 한 장면 3초 이상, 아웃트로는 두 줄까지
- 마지막 프레임 = 첫 프레임 (루프)
- 소리는 넣지 않고 앱에서 고른다
- Shorts: 외부 링크가 안 눌림 → "앱스토어에서 '로킷' 검색", 하단 1500px 아래 비우기
- 릴스: 그리드 3:4 크롭 → 텍스트는 y 270~1680, CTA는 "프로필 링크", 커버 따로 지정
